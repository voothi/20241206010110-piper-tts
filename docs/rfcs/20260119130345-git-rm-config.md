# RFC: Remove config.ini from Git Index

**Staging:** Development
**Request ZID:** 20260119130345

## Implementation Details

### Analytics
- `config.ini` contains user-specific paths (e.g., `ffplay_executable`) and should not be tracked by the version control system to avoid accidental leaks or configuration conflicts.
- A `config.ini.template` exists to provide a starting point for new users.
- The file was previously tracked in the git index.

### Decisions
- Executed `git rm --cached config.ini` to remove the file from the repository index while preserving the local file.
- Verified that `config.ini` is listed in `.gitignore` to prevent it from being re-added in future commits.
- Users should now use `config.ini.template` as a base for their local configuration.
